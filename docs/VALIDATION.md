# Проверка рефакторинга

Дата: 30 сентября 2026. Основа: amper24/HSPM-App, commit `dd7b30b86e78459922e41f70f7e384d5e997c210`. Проверки выполнялись локально на Windows с PHP 8.4.26, SQLite и Node.js; отдельная тестовая база не содержит рабочих данных пользователя.

## Выполненные проверки

- 17 PHPUnit-тестов, 77 утверждений: сессия и выход, права чтения/записи, CRUD, фильтры, запрет изменения последнего администратора, синхронизация аудиторий, отмена занятия, откат импорта и приватность экспорта.
- 4 Vitest-теста: фильтр со значением 0, форматирование времени, отмена формы, защита от устаревшего ответа.
- Production-сборка Vite проходит; Vue и CSS включены в локальные файлы сборки, CDN не требуется.
- Composer audit: известных уязвимостей в установленном наборе PHP-зависимостей не найдено на момент проверки.
- npm audit --omit=dev: два предупреждения низкой серьёзности (Vue 2 и зависящий от него Vuex; GHSA-5j4c-8p2g-v4jx). Vue 2 сохранён по исходному ТЗ; переход на Vue 3 требует отдельного согласования требований. Высоких и критических предупреждений не обнаружено.
- Тест числа SQL подтверждает одинаковое число запросов для страницы из 1 и 20 занятий; счётчики главной выполняют один запрос предметных данных.
- Исходные Excel загружались дважды. Для успешно распознанных файлов повторная загрузка не увеличила число строк ни в основной таблице, ни в связях.

- В браузере проверены вход администратора и создание аудитории через API; JavaScript-ошибок не зафиксировано.
- HTTP-запрос записи без CSRF-токена отклонён с кодом 419.

## Границы проверки

Docker-образ и MySQL 8.4 на этой машине не запускались. Добавлен отдельный набор настроек PHPUnit и CI для MySQL; наличие workflow не означает, что удалённый CI уже прошёл. Перед переносом рабочей БД нужен прогон на её копии и проверка Docker на целевом сервере.

Проверка повторного импорта подтверждает техническую идемпотентность, но не заменяет построчную предметную сверку всех Excel. Недельные сетки содержат объединённые ячейки, чередование недель и текстовые исключения; календарное разворачивание и применение журнала переносов не реализованы. Несколько преподавателей в одной ячейке остаются текстом экзаменатора.

Нагрузка большого количества одновременных пользователей, норматив 99,9% доступности и гарантированное время ответа до 5 секунд на целевой инфраструктуре не проверялись.
