## Что уже сделано

### Docker
- Образ: `php:7.2.34-apache` + GD, mbstring, zip, pdo_mysql
- MySQL 5.7.21 в отдельном контейнере
- Запуск: `docker compose up -d`
- Entrypoint автоматически создает БД, импортирует схему, генерирует config.php

### База данных (MySQL 5.7.21)
5 таблиц:
- `users` — пользователи (admin/user)
- `classrooms` — аудитории
- `teachers` — преподаватели
- `schedule` — расписание занятий
- `software` — программное обеспечение

Индексы по ключевым полям (building, room_type, last_name, department, employment_type, date, transfer_cancel, is_occupied).  
Внешние ключи: schedule → classrooms (CASCADE), schedule → teachers (SET NULL).

### Бэкенд (PHP 7.2.34)
REST API эндпоинты:
- `POST /api/auth/login` — вход
- `POST /api/auth/logout` — выход
- `GET /api/auth/me` — текущий пользователь
- `GET/POST/PUT/DELETE /api/teachers` — CRUD преподавателей
- `GET/POST/PUT/DELETE /api/classrooms` — CRUD аудиторий
- `GET /api/classrooms/search?q=` — поиск аудиторий
- `GET /api/classrooms/free?date=&pair=` — свободные аудитории
- `GET/POST/PUT/DELETE /api/schedule` — CRUD расписания
- `GET/POST/PUT/DELETE /api/software` — CRUD ПО
- `GET/POST/PUT/DELETE /api/users` — CRUD пользователей (только admin)
- `POST /api/import` — импорт данных из Excel
- `GET /api/export?type=` — экспорт в Excel

Разграничение прав: `requireAuth()` / `requireAdmin()`.

### Фронтенд (Vanilla JS, без CDN)
Одностраничное приложение (SPA):
- **Главная** — дашборд со статистикой
- **Преподаватели** — CRUD + фильтр по ФИО/кафедре/занятости
- **Аудитории** — CRUD + поиск
- **Расписание** — CRUD + поиск свободных + цветовое выделение переносов/отмен
- **Программное обеспечение** — CRUD
- **Импорт данных** — загрузка Excel
- **Экспорт / Отчеты** — выгрузка в Excel
- **Пользователи** — управление (только admin)

Стилизация — чистый CSS, без фреймворков.

### Тесты
- **БД**: 23/23 ✅ — подключение, таблицы, структура, индексы, FK, CASCADE
- **API**: 20/20 ✅ — аутентификация, CRUD, права доступа, поиск
