# Инструкция пользователя и администратора

Система «Учебный отдел ВШПМ» — веб-приложение для учёта преподавателей, аудиторий,
программного обеспечения и расписания занятий.

---

## 1. Вход в систему

1. Откройте в браузере адрес приложения (по умолчанию `http://localhost:8080`).
2. Введите логин и пароль, нажмите **«Войти»**.
3. После входа открывается **Главная** страница.

> При неверном логине или пароле система покажет сообщение об ошибке.

**Права ролей:**

| Действие | Пользователь (`user`) | Администратор (`admin`) |
|----------|:---:|:---:|
| Просмотр данных, поиск, фильтры | ✔ | ✔ |
| Добавление / изменение / удаление записей | — | ✔ |
| Импорт / экспорт данных | — | ✔ |
| Очистка таблиц | — | ✔ |
| Управление пользователями | — | ✔ |

---

## 2. Главная страница (дашборд)

- Вверху — текущая дата и время (обновляются автоматически).
- **Статистика:** количество преподавателей, аудиторий, записей расписания и ПО.
- **Фильтр по дате** — выбор даты занятий.
- **Поиск группы** — начните вводить шифр группы (например `1-ГИД-19`),
  появится список подсказок; выберите нужную или нажмите Enter.
- Ниже отображается расписание на выбранную дату и группу.

---

## 3. Раздел «Преподаватели»

Показывает список преподавателей (ФИО, кафедра, должность, степень, звание,
форма занятости, email, телефон).

**Поиск и фильтры (сверху):**
- текстовый поиск по ФИО;
- кафедра;
- степень;
- звание;
- форма занятости;
- перенос/отмена (преподаватели, у которых есть перенесённые или отменённые занятия).

---

## 4. Раздел «Аудитории»

Показывает список аудиторий (номер, корпус, тип, ПК, проектор, колонки, мест).

**Фильтры:** корпус, тип, проектор, колонки, сортировка по местам, текстовый поиск.

**Поиск свободной аудитории (отдельный блок):**
1. Укажите дату и при необходимости пару (1–8), корпус, проектор, колонки, минимальное число мест.
2. Нажмите **«Найти»**.
3. Система покажет список аудиторий, свободных на указанную дату/пару.

---

## 5. Раздел «Расписание»

Показывает записи занятий: дата, время, группа, дисциплина, вид, экзаменатор,
аудитория, перенос/отмена.

**Цветовое выделение:**
- строки с **переносом** выделены жёлтым;
- строки с **отменой** выделены красным.

**Фильтры:** текстовый поиск по дисциплине/группе/преподавателю, перенос/отмена.

---

## 6. Раздел «Программное обеспечение»

Показывает ПО по аудиториям (название, аудитория, корпус).
Фильтры: текстовый поиск по названию, корпус.

---

## 7. Работа администратора

### Добавление записи
На странице таблицы нажмите **«+ Добавить»** — в верхней части таблицы появится
форма, заполните поля и нажмите **«✓ Сохранить»**.

### Редактирование / удаление
- **«Ред»** — открывает форму редактирования записи.
- **«Уд»** — удаляет запись (с подтверждением).

### Импорт данных
1. Откройте раздел **«Импорт данных»** (доступен только администратору).
2. Выберите тип данных:
   - `Преподаватели` — файл «Список преподавателей…»;
   - `Аудитории` — файл технической характеристики аудиторий;
   - `Расписание` — файлы расписания занятий/сессии;
   - `Программное обеспечение` — файл технической характеристики ПО.
3. Выберите файл `.xlsx` или `.xls`.
4. При импорте расписания можно включить:
   - «Создавать отсутствующих преподавателей из расписания»;
   - «Заменить» — удалить записи, которых больше нет в файле (в диапазоне дат файла).
5. Нажмите **«Загрузить»** и дождитесь сообщения о результате.

> **Порядок импорта:** сначала преподаватели, затем аудитории, затем ПО, затем расписание —
> так корректно связываются преподаватели и аудитории с занятиями.

### Экспорт в Excel
На страницах «Преподаватели», «Аудитории», «Расписание», «ПО» есть кнопка
**«Экспорт Excel»**. На «Аудиториях» дополнительно доступен **«Отчёт по загруженности»**.

### Управление пользователями
Раздел **«Пользователи»** (только администратор) позволяет создавать, изменять и удалять
учётные записи. Роль может быть `admin` или `user`.

### Очистка таблицы
Кнопка **«Очистить»** (только администратор) полностью удаляет все записи текущей таблицы
(требует двойного подтверждения).

### Командная строка (CLI)
В контейнере доступна утилита `hspm-admin` для управления без браузера:

```bash
docker exec vshpm-app php /var/www/html/hspm-admin help
```

Подробный список команд см. в `README.md`.

---

## 8. Резервное копирование

Администратор может создать резервную копию БД и при необходимости восстановить её:

```bash
docker exec vshpm-app php /var/www/html/hspm-admin backup
docker exec vshpm-app php /var/www/html/hspm-admin restore
```

---

## 9. Тёмная тема

Кнопка в правом нижнем углу переключает светлую/тёмную тему. Выбор сохраняется в браузере.

---

## 10. Завершение работы

Нажмите **«Выйти»** в правом верхнем углу, чтобы завершить сеанс.
