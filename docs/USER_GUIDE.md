# Работа с приложением

Войдите под учётной записью, которую создал администратор. Обычный пользователь может просматривать данные, искать аудитории и выгружать Excel. Администратор дополнительно создаёт, изменяет и удаляет записи, загружает Excel и управляет пользователями.

## Главная и справочники

На главной выберите дату и группу. Счётчики показывают объём справочников. Разделы «Преподаватели», «Аудитории», «Расписание» и «Программное обеспечение» содержат поиск, фильтры и страницы результатов. Значение «Нет» в фильтре оборудования действительно означает отсутствие, а не отключение фильтра.

Нажмите «Добавить» или «Ред», заполните форму и сохраните. Ошибки показаны возле формы; введённые данные не теряются. «Отмена» закрывает черновик. Переносы и отмены выделяются цветом. В форме расписания можно указать несколько аудиторий: `Д234, Д237`; `ДО` означает дистанционное занятие.

При редактировании пользователя пустое поле пароля сохраняет прежний пароль. Нельзя удалить собственную учётную запись или лишить систему последнего администратора.

## Свободные аудитории

В разделе «Аудитории» выберите дату, пару, корпус, оборудование и минимальное число мест. «Весь день» ищет аудитории без занятых календарных занятий в выбранную дату. Учитываются все аудитории занятия, включая дополнительные; отменённое занятие аудиторию не занимает.

Недельные сетки без дат требуют отдельной календарной привязки. Нельзя считать результат поиска гарантией свободного помещения, если в базе есть только такие сетки: они не разворачиваются автоматически в даты.

## Импорт

Выберите тип и файл `.xlsx` или `.xls` размером до 20 МБ. Для файла «Тех_хар_ка_ПО_ауд.xlsx» выполните два импорта: «Аудитории» и «Программное обеспечение». Исходный лист преподавателей должен содержать ФИО, иначе записи не создаются.

Расписание поддерживает табличные формы с заголовками и недельные сетки. Недельные записи сохраняются без придуманной даты и видны в общем списке расписания. Разрешение создания отсутствующих преподавателей относится к отсутствующим однозначным ФИО; несколько людей в одной ячейке сохраняются текстом экзаменатора.

Обычный импорт добавляет или обновляет записи. В режиме замены занятия групп из файла в его диапазоне дат, которых больше нет в файле, удаляются. Используйте этот режим только для полного снимка выбранных групп. Если хотя бы у одной строки нет даты или группы, замена отклоняется целиком.

ПО из файла заменяет состав программ только перечисленных аудиторий. Пустая колонка существующей аудитории означает отсутствие ПО и очищает её список.

Журнал переносов с диапазонами дат не загружается как снимок расписания. Примените его изменения вручную к соответствующим занятиям. Это предотвращает ошибочные массовые отмены при неоднозначных сокращениях групп.

## Экспорт и отчёт

«Экспорт Excel» выгружает выбранный справочник целиком, независимо от фильтра текущей страницы. «Отчёт по загруженности» показывает число занятий, занятых записей, переносов и отмен для каждой аудитории; это не процент загрузки и не число проведённых часов. Скачать временный файл может только создавший его пользователь.

Файлы преподавателей, аудиторий, расписания и ПО используют совместимые с импортом формы. Связь с точным идентификатором преподавателя не кодируется в Excel: при повторной загрузке она определяется по имени, неоднозначные имена остаются текстом. Отчёт не предназначен для обратного импорта.
