# Система сбора и поиска данных для учебного отдела ВШПМ СПбГУПТД

```bash
git clone https://github.com/amper24/HSPM-App.git && cd HSPM-App && chmod +x setup.sh && ./setup.sh
```

## 1. Описание архитектуры и используемых технологий

### Кодовая база
Приложение разработано и протестировано на следующем окружении:

- **ОС**: Linux Ubuntu 16.04 LTS
- **PHP**: 7.2.34
- **MySQL**: 5.7.21
- **Apache**: 2.4 с mod_rewrite
- **Vue**: 2.7.14
- **Element UI**: 2.15.14

### Архитектура
Приложение построено по архитектуре **клиент-сервер** (SPA + REST API):

- **Фронтенд (клиентская часть)**: Vue 2 + Element UI — одностраничное приложение (SPA)
- **Бэкенд (серверная часть)**: PHP 7.2.34 — RESTful API
- **База данных**: MySQL 5.7.21
- **Веб-сервер**: Apache 2.4 с mod_rewrite

### Технологический стек

| Уровень | Технология | Версия | Назначение |
|---------|------------|--------|------------|
| Клиент | Vue 2, Element UI, Axios | 2.7.14 / 2.15.14 / 0.27.2 | Интерфейс пользователя |
| Сервер | PHP, PDO | 7.2.34 | Бизнес-логика, REST API |
| БД | MySQL, InnoDB | 5.7.21 | Хранение данных |
| Импорт/экспорт | PhpSpreadsheet | ^1.29 | Работа с Excel-файлами |

### Ключевые модули

#### Серверная часть (`api/`)
- **config.php** — конфигурация БД, CORS, сессии, хелпер-функции (авторизация, валидация)
- **index.php** — главный роутер: парсит URL и направляет запросы в соответствующие обработчики
- **auth.php** — аутентификация (логин/логаут/проверка сессии)
- **teachers.php** — CRUD преподавателей + поиск по ФИО, кафедре, форме занятости
- **classrooms.php** — CRUD аудиторий + поиск по всем полям + поиск свободных аудиторий
- **schedule.php** — CRUD расписания + массовое удаление при обновлении импорта
- **software.php** — CRUD программного обеспечения
- **import.php** — массовый импорт из Excel (xls, xlsx) для всех сущностей
- **export.php** — экспорт данных в Excel + формирование отчетов
- **users.php** — управление пользователями (администратор)

#### Клиентская часть
- **index.html** — главная страница SPA с разметкой
- **js/api.js** — клиентская библиотека для взаимодействия с REST API через Axios
- **js/app.js** — Vue-приложение со всеми компонентами:
  - `login-form` — форма авторизации
  - `dashboard-page` — главная панель (статистика, поиск свободных аудиторий, последние переносы/отмены)
  - `schedule-page` — просмотр и редактирование расписания (с цветным выделением переносов/отмен)
  - `classrooms-page` — управление аудиториями
  - `teachers-page` — управление преподавателями
  - `software-page` — управление реестром ПО
  - `import-page` — загрузка Excel-файлов (4 вкладки по типам данных)
  - `export-page` — экспорт данных и формирование отчетов
  - `users-page` — управление пользователями (только admin)
- **css/style.css** — кастомные стили

### Разграничение прав доступа
- **admin** — полный доступ: CRUD всех сущностей, импорт/экспорт, управление пользователями
- **user** — только просмотр данных и поиск; не может редактировать, удалять, импортировать

## 3. Инструкция по развертыванию

### Способ установки

| Способ | Сложность | Рекомендация |
|--------|-----------|--------------|
| **Docker + setup.sh** | ⭐ Просто | Для быстрого запуска (1 команда) |
| **Docker вручную** | ⭐⭐ Средне | Если нужен контроль над параметрами |
| **Ручная установка** | ⭐⭐⭐ Сложно | Только для bare-metal серверов |

---

### ⚡ Способ 1: Docker — установка одной командой с GitHub (рекомендуется)

**Требования:** Docker и Docker Compose.

```bash
git clone https://github.com/amper24/HSPM-App.git && cd HSPM-App && chmod +x setup.sh && ./setup.sh
```

Скрипт `setup.sh` выполнит:
1. Интерактивную настройку `.env` (пароли БД, порты)
2. Сборку Docker-образов
3. Запуск контейнеров (PHP 7.2.34 + Apache + MySQL 5.7.21)
4. Автоматическую инициализацию базы данных
5. Ожидание готовности и вывод итоговой справки

После завершения:
```
http://localhost:8080/
Логин: admin
Пароль: admin123
```

**Управление контейнерами:**
```bash
docker-compose ps              # статус
docker-compose logs -f app     # логи
docker-compose down            # остановка
docker-compose up -d           # запуск
```

**Настройка через переменные окружения (.env):**
```ini
MYSQL_ROOT_PASSWORD=root_secret
DB_NAME=vshpm_edu
DB_USER=vshpm
DB_PASS=vshpm_secret
DB_PORT=3307          # порт MySQL на хосте
APP_PORT=8080         # порт приложения на хосте
```

### 🐳 Способ 2: Docker вручную (с конфиг-файлом)

Скопируйте шаблон конфигурации `.env.example` в `.env`, отредактируйте при необходимости и запустите:

```bash
# 1. Скопировать и настроить конфиг
cp .env.example .env
nano .env   # или vim .env — измените пароли/порты при необходимости

# 2. Запустить
docker-compose up -d --build
```

При первом запуске:
- MySQL инициализируется со схемой из `database/schema.sql`
- PHP-контейнер дожидается готовности БД, применяет схему
- Composer-зависимости устанавливаются при сборке образа

### 🖥️ Способ 3: Ручная установка (без Docker)

#### Системные требования
- **ОС**: Linux Ubuntu 16.04 / 18.04 / 20.04
- **Веб-сервер**: Apache 2.4 с mod_rewrite
- **PHP**: 7.2.34 (расширения: pdo, pdo_mysql, mbstring, json, fileinfo, zip)
- **MySQL**: 5.7.21
- **Composer** (для установки PhpSpreadsheet)

#### Шаг 1. Установка зависимостей ОС
```bash
sudo apt update
sudo apt install apache2 mysql-server php7.2 php7.2-mysql php7.2-mbstring php7.2-json php7.2-zip php7.2-xml composer unzip
sudo a2enmod rewrite
sudo systemctl restart apache2
```

#### Шаг 2. Копирование файлов
```bash
sudo cp -r ./* /var/www/html/
```

#### Шаг 3. Настройка прав
```bash
sudo chown -R www-data:www-data /var/www/html/
sudo chmod -R 755 /var/www/html/
sudo mkdir -p /var/www/html/uploads /var/www/html/exports
sudo chmod -R 777 /var/www/html/uploads /var/www/html/exports
```

#### Шаг 4. Создание базы данных
```bash
mysql -u root -p < /var/www/html/database/schema.sql
```

#### Шаг 5. Настройка подключения к БД
Отредактируйте `/var/www/html/api/config.php`:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'vshpm_edu');
define('DB_USER', 'root');
define('DB_PASS', 'ваш_пароль');
```

#### Шаг 6. Установка PhpSpreadsheet
```bash
cd /var/www/html
composer require phpoffice/phpspreadsheet
```

#### Шаг 7. Настройка Apache
Убедитесь, что в конфигурации Apache разрешен `.htaccess`:
```apache
<Directory /var/www/html>
    AllowOverride All
    Require all granted
</Directory>
```
```bash
sudo systemctl restart apache2
```

#### Шаг 8. Вход в систему
Откройте: `http://<ваш-сервер>/`

**Учетные данные по умолчанию:**
- Логин: `admin`
- Пароль: `admin123`

**Сразу после входа смените пароль администратора!**

## 4. Инструкция для администратора

### Управление аудиториями
1. Перейдите в раздел **Аудитории**
2. Кнопка **"Добавить аудиторию"** — создать новую запись
3. Кнопка **"Изм."** — редактировать существующую
4. Кнопка **"Удалить"** — удалить аудиторию (вместе со связанным расписанием!)
5. Используйте фильтры для быстрого поиска

### Управление преподавателями
1. Раздел **Преподаватели**
2. Поиск по ФИО, кафедре, форме занятости
3. CRUD операции аналогично аудиториям

### Управление расписанием
1. Раздел **Расписание**
2. Фильтры: дата, корпус, вид занятия, перенос/отмена
3. **Переносы выделены красным цветом**, отмены — оранжевым
4. При добавлении/редактировании записи можно указать статус "перенос" или "отмена"

### Управление ПО
1. Раздел **Программное обеспечение**
2. Ведение реестра ПО по аудиториям

### Импорт данных
1. Раздел **Импорт данных** (4 вкладки)
2. Выберите вкладку, соответствующую типу импортируемых данных
3. Перетащите Excel-файл или нажмите для выбора
4. Нажмите **"Загрузить"**
5. Для расписания доступна опция "Заменить существующее расписание за период"

### Экспорт / Отчеты
1. Раздел **Экспорт / Отчеты**
2. Выберите тип данных для экспорта
3. Для преподавателей — фильтр по кафедре
4. Для расписания — диапазон дат
5. **Сводный отчет** — загруженность аудиторий, статистика переносов/отмен

### Управление пользователями
1. Раздел **Пользователи**
2. Создание, редактирование, удаление учетных записей
3. Нельзя удалить самого себя

## 5. Инструкция для пользователя

Пользователь с ролью `user` имеет доступ только для чтения:

- **Просмотр** аудиторий, преподавателей, расписания, ПО
- **Поиск** по любым критериям через фильтры
- **Главная панель** — поиск свободных аудиторий на выбранную дату/пару
- Просмотр последних переносов и отмен занятий

Пользователь НЕ может:
- Добавлять, изменять или удалять данные
- Импортировать или экспортировать файлы
- Управлять пользователями
